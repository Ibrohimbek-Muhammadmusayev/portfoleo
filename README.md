# ⚡ Ibrohimbek - Senior Frontend Engineer Portfolio

Eng zamonaviy, 3D interaktiv fizikaga va animatsiyalarga ega bo'lgan shaxsiy portfolio veb-ilovasi.

## 🚀 Texnologiyalar
- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion** (3D Interactive Drag, Mouse Tilt & Scroll Morphism)
- **Lucide Icons**
- **Canvas Confetti**

## 📦 O'rnatish va Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Loyihani rivojlantirish rejimida ishga tushirish
npm run dev

# Ishlab chiqarish (Production) uchun build qilish
npm run build
```
